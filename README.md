# Cadence
Cadence - это микросервисная платформа для совместной работы с задачами в формате канбан-досок. Команды создают доски, ведут карточки задач и видят все изменения в реальном времени.
Проект решает не только ведение задач, но и автоматизацию рутины. Напоминания о дедлайнах, подсчет прогресса доски и регулярные дайджесты «что сделано за неделю».
